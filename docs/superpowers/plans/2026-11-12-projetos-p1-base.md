# Projetos — entrega P1 (base)

Especificação: `src/modulos/projetos/especificacao.md` (PR #108). Proposta: issue #107.
Esta entrega faz só a **P1**: módulo, permissões, ideia, porte, assumir responsável, configurações,
porta 1 com pareceres, decisões, alçada e histórico. P2 a P7 ficam para issues próprias.

## Tarefas
1. Domínio puro (`dominio/`): etapas, porte, pareceres exigidos, alçada, regras da porta.
2. Abas (`dados/tabelas.ts`): Projetos, Portas, Pareceres, Decisoes, ConfigProjetos, HistoricoProjetos.
3. Casos de uso (`aplicacao/`): ideias, portas, configurações, consultas (quem vê o quê).
4. Manifesto, composição (`registro-modulos`), dados fictícios.
5. Telas e ações em `src/app/(elo)/projetos/`.
6. Testes (domínio, acesso, ideias, portas, configurações) e documentação (CLAUDE.md do módulo).
7. `npm run verificar` e `npm run build`; PR.
