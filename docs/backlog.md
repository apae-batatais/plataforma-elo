O backlog fica no **quadro "Elo"** do GitHub Projects (organização apae-batatais), desde
8 de novembro de 2026. Cada item é uma issue do repositório; a ordem dentro de cada coluna é a
prioridade, decidida pela Diretoria. Como funciona: `docs/metodologia.md`.

Os itens em aberto deste arquivo viraram as issues #53 e #55 a #68. As pendências da Diretoria
fora do código viraram as issues #69 e #70 (etiqueta `pendência da Diretoria`). O que já foi
concluído está no histórico dos Pull Requests.

O que fica para depois em cada app continua em `docs/roadmap.md`.
